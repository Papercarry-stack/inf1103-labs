2.1: Student discount

Without Strategy, the Order class changes, specifically calculate_total(), which gets another elif. That breaks the Open/Closed Principle.
With Strategy, Order doesn’t change at all. You add a new StudentDiscount class with its own apply().

2.3: Order totalling 250

With BulkDiscount(200, 20): 250 is at or above 200, so the result is 230.
After set_discount(PercentageDiscount(10)): 225. The new strategy replaces the old one rather than stacking on it, and it works from the raw 250.

2.4: Order and DiscountStrategy

Association. A discount isn’t part of an order, it’s something the order uses. Two orders can share one PercentageDiscount object, which wouldn’t be possible with composition.
Multiplicities: each order has exactly one strategy (NoDiscount is the default), so the strategy end is 1. One strategy can serve many orders, so the Order end is 0..*.

3.2: ProductFactory.create("service", ...)

The else branch runs and its raise ValueError(...) line fires, with the message “Unknown product type: service”.
If nothing catches it, Python prints a traceback and the program stops. In load_products() it is caught, so that row is skipped.
